# Raw V2 UI TB Visibility Note

The Raw V2 upload result must not use full-TB net variance as the primary indicator of whether TB was parsed. A complete trial balance can legitimately net to zero.

For TB, the UI should prominently show:
- parsed COA count
- non-zero COA count
- detected fiscal period
- net monthly variance, explicitly labeled as net

For CC sources, the UI should continue showing detail count, non-zero count, total, Debit, and reconciliation difference.
